# 文本分析 Skill

当用户需要对一段已有文本做确定性统计时使用本 Skill，例如：

- 统计字符数、中文字符数、英文单词数和行数；
- 统计某个关键词出现的次数；
- 获取文本长度、首行和内容预览等基本信息。

## 使用原则

1. 用户要求精确计数时调用工具，不要依靠目测估算。
2. 调用工具时，原样传入用户提供的文本，不要擅自改写或翻译。
3. 关键词统计默认忽略英文大小写；只有用户明确要求区分时，
   才把 `case_sensitive` 设置为 `true`。
4. 工具返回的是结构化原始数据。最终回答应选择与用户问题相关的字段，
   用自然语言说明结果，不需要机械地输出全部 JSON。
5. 本 Skill 只分析用户已经提供的文本，不负责读取文件、网页或外部数据。

## 工具选择

- `count_text`：用户询问字数、字符数、单词数或行数。
- `count_keyword`：用户询问一个词语或短语出现了多少次。
- `summarize_text_info`：用户想快速了解文本大小、首行或内容预览。
